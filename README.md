# AtCoder Solutions

AtCoderの解答コードをまとめたリポジトリです。

## 使用言語

- C++
- TypeScript

## ローカル実行と保存

初回のみ TypeScript の実行環境をインストールします。

```sh
npm install
```

`main/main.cpp` または `main/main.ts` に解答を書き、次のコマンドで実行します。

```sh
./acrun cpp
./acrun ts
```

片方だけにコードが入っている場合は `./acrun` だけでも自動判定します。保存時の拡張子も、コードが入っている `main` ファイルから自動判定します。

```sh
./acsave ABC/A/000
```
