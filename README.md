# AtCoder Solutions

AtCoderの解答コードをまとめたリポジトリです。

## 使用言語

- C++
- TypeScript

## 実行・保存

`main/main.py` など、`main/main.*` に任意の拡張子でファイルを追加できます。VS Codeでは保存後、`Ctrl+Shift+B` でアクティブなファイルを実行できます。「Tasks: Run Task」から `save active main file` を選ぶと、アクティブな `main/main.*` を入力した保存先へ移します。複数タブが開いていても対象は選択中の1枚だけで、拡張子は自動で引き継がれます。

ターミナルでは対象ファイルを明示できます。

```sh
./debug main/main.py
./acsave ABC/A/123 main/main.py
```

保存は任意の拡張子に対応します。実行はC/C++、TypeScript、JavaScript、Python、Ruby、Rust、Go、Bash、PHP、Perl、Luaに標準対応します。その他は `ac-runners/拡張子` に、`$1` で渡されるファイルを実行するBashスクリプトを追加できます。
